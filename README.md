# Team Dependency Risk Analyzer

## Project Goal
Identify project risks caused by employee dependency, knowledge concentration, and skill ownership.

## Tech Stack
- Java 21
- Spring Boot
- Spring Security
- JWT Authentication
- MySQL
- Hibernate / JPA
- ReactJS
- Maven
- GitHub

## Core Modules
1. Authentication
2. Employee Management
3. Skill Management
4. Project Management
5. Module Management
6. Ownership Management
7. Dependency Risk Analysis
8. Skill Gap Analysis
9. Employee Exit Simulation
10. Dashboard & Reports

## User Roles

### Admin
- Manage Employees
- Manage Skills
- Manage Projects
- Assign Ownership

### Manager
- View Risk Dashboard
- Run Exit Simulations
- View Reports
- Analyze Skill Gaps
